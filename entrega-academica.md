
# EsperançaGestor
## ONG Rede Solidária Esperança

Sistema acadêmico demonstrativo para organização da gestão social.

### Funcionalidades
- Cadastro de beneficiários.
- Cadastro de doadores.
- Cadastro de voluntários.
- Registro de doações.
- Consulta, edição e exclusão de registros.
- Painel administrativo.
- Verificação do status da API com data e hora.

### Tecnologias utilizadas
- JavaScript
- Node.js
- Express
- Vite
- HTML e CSS

### Como executar
1. Instale o Node.js.
2. Abra a pasta do projeto no terminal.
3. Execute npm install.
4. Execute npm run dev.
5. Inicie também o servidor da API conforme a configuração do projeto.
6. Acesse http://localhost:5173.

Projeto desenvolvido para fins acadêmicos.
